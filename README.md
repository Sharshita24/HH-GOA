## 🧩 Overview

This project is a branded photo frame generator for **Hacker House Goa 2026**. It lets users upload a photo, adjust the crop and placement, apply a custom HH Goa frame, and export a polished square image ready for social sharing.

The experience is designed to feel premium, event-driven, and aligned with the official HH Goa aesthetic.

---

## ✨ Features

- Upload any profile image
- Support for common image types including HEIC/HEIF files
- Real-time canvas preview
- Zoom, rotation, and positioning controls
- Multiple branded frame styles
- One-click download of the final framed image
- Team frame builder flow
- Share-ready composition for posting with #FrameInGoa

---

## 🛠️ Tech Stack

- Next.js 14
- React + TypeScript
- Tailwind CSS
- HTML5 Canvas
- Browser-side HEIC conversion support
- Vercel deployment

## 🚀 Local Setup

### 1. Clone the repo
```bash
git clone https://github.com/Sharshita24/HH-GOA.git
cd HH-GOA
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the app locally
```bash
npm run dev
```

Open: http://localhost:3000

### 4. Production build
```bash
npm run build
```
